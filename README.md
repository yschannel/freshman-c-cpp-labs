# 大一 C / C++ 课程实验

整理自大学一年级的 C、C++ 课程学习文件，保留实验、作业、课堂示例和期末项目，按原有目录归档。

## 目录

| 目录 | 内容 |
| --- | --- |
| `C/CS Intro Assignment/` | C 课程分单元作业与期中练习 |
| `C/` 其他文件 | C 基础练习与少量 C++ 试写代码 |
| `CPP/cpp/` | C++ 入门与输入输出练习 |
| `CPP/cpp+/` | C++ 各单元示例、作业和练习 |
| `CPP/FinalProject.v7/portfolio/` | C++ 学习记录管理系统期末项目 |

## 编译与使用

本仓库是多个独立练习的合集。请按具体题目编译，许多文件各自含有 `main`，不能将整个仓库一次性链接为一个程序。

```bash
# 单文件 C 练习：将路径替换为具体实验文件
gcc "C/CS Intro Assignment/Unit01/001.c" -o hello

# 单文件 C++ 练习
g++ -std=c++17 "CPP/cpp/01/01alohaworld.cpp" -o hello_cpp
```

多文件练习请结合目录中的头文件和 `CMakeLists.txt` 编译；期末项目的编译、运行方法见其 README。部分练习使用 Windows 相关函数，需在对应环境下运行或自行适配。
